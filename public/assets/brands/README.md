Brand colours are the primary colours each brand's own website uses (Oct 12, 2026): Milwaukee `#DB011C`,
DeWalt `#FEBD17`, Makita `#008290` (teal; its logo is red), Simpson Strong-Tie `#FF5308`.

Official artwork from the vendors (dealer portals) can replace these files at any time: keep the file names, and
update `logoAspect` in `public/js/core/brands.js` if the proportions change.
